# استوديو الصوت — Studio Voice

Offline Android voice-enhancement app (DeepFilterNet fast engine + DPDFNet
ONNX pro engine, native Kotlin mastering: v2 noise recipe + v3B warm-radio
tone). 100% on-device, no account, no network.

Build: GitHub Actions workflow `Build Studio Voice (debug APK)` — the
DPDFNet model is downloaded in CI from huggingface.co/Ceva-IP/DPDFNet and
SHA-256-verified (it is not stored in this repo).
